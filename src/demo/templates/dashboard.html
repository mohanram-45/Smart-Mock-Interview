How it works

A real interview shape, honest feedback

Every part of the report says where it came from, so you know how much weight to give it.

  1. Choose

    Pick a role and, if you like, paste a job description. The plan comes from the curated bank and never changes with how you score.

  2. Answer

    Talk it through: an introduction, role-based questions, a follow-up now and then, and a practical exercise. Drafts are kept; Python questions get a code editor.

  3. Review

    Get a report with the questions asked, your answers, the topics covered and what to practise next.

Similarity (Sentence-BERT) secondary

How close your wording and meaning are to a reference answer. It sits in the technical details, is not a technical grade and has not been checked against human markers.

Concept check experimental

Opt-in. Looks for the concepts a good answer states and shows only findings it has evidence for. Not validated.

Code reading experimental

Opt-in. Reads your Python as text against a written test plan. Your code is never executed.
